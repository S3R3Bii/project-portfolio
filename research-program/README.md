# Research portfolio program

Fifty scoped research studies connect practical decisions to inspectable evidence. Each published repository explains its finding or current result, how to reproduce it, and the limits on what it can support. Original broad proposals and failed source gates remain visible as design history.

**All 50 scoped studies and 50 independent manuscripts are released.** The [manuscript index](RESEARCH_PAPERS.md) links the reviewed PDF and LaTeX versions with their recorded passing checks.

The final releases test [fiscal versus calendar revenue pooling](https://github.com/S3R3Bii/revenue-reporting-calendars) and return [conditional replacement ranges for incomplete supplier data](https://github.com/S3R3Bii/wheat-supplier-stress). The [research-paper recommendation engine](https://github.com/S3R3Bii/research-paper-recommender) includes an implementation exercise and an abstain option when evidence is insufficient.

Source limitations are part of the results. A scoped release does not validate every original proposal: for example, the original wheat coverage gate still fails, and its replacement ranges depend on explicit capacity assumptions. No source-access note is counted as an executed study. Separate formal-publication projects, including Azure optimization, remain private.

Public packages contain eligible factual subsets, original code, results, figures, source references, implementation exercises and validation receipts. Predictive studies follow the [model-validation standard](MODEL_VALIDATION_STANDARD.md); all studies follow the [GitHub working process](GITHUB_WORKFLOW.md). The [skills map](SKILLS_AND_SEQUENCE.md) retains the program's method and sequencing context; project READMEs identify the work actually executed.
