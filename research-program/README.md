# Research portfolio program

Fifty independent studies organized around decisions, measurement problems and testable methods. These are research protocols, not fifty completed projects. Strong findings, negative results and failed data-access gates are recorded as they occur.

Public packages contain eligible data, retrieval scripts, analysis, SQL, figures, source references and validation receipts. Independent research manuscripts may accompany their reviewed GitHub study packages; manuscripts intended for formal publication remain private. A project advances only after its data and results exist.

[Model validation standard](MODEL_VALIDATION_STANDARD.md) requires declared objectives, protected validation/test splits and independent metric recomputation.

[GitHub working process](GITHUB_WORKFLOW.md): focused commits, issues, pull requests and verifiable releases throughout each study.

## Release standard

A concise first layer states the decision, measured finding, useful next step and material limitation. Methods, data, tuning logs, failed checks and reproduction details remain accessible underneath. No invented revenue, savings, production use, scientific novelty or professional tenure.

Original prose and code are written for each question. Reusing a tested retrieval or plotting utility is allowed; repackaging the same analysis under fifty titles is not.

The research sequence starts with complaint-capacity forecasting, point-in-time financial data integrity, electricity forecast correction, kinematic event detection and model-selection efficiency. Access, rights and data fitness can change that sequence.
