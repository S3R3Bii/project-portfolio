# Portfolio figures — November 18, 2026

Nine figures, each exported at 1600×900 and 3200×1800 in PNG and WebP. Colors and typography are shared across the figures. Numbers describe saved results; no models were retrained for this presentation revision.

| Figure | Evidence and interpretation |
| --- | --- |
| Doppler candidate scatter | Public anonymized scores for 358 candidates under each source-spacing assumption. The supplied reference ranks first by curve fit, second/fifth by spectral contrast. The two objectives are different; close alternatives remain. |
| Doppler spectrum and relative map | Cropped, whitened recorded spectrum with fourth/eighth modeled harmonics. The observer estimate is about 79.1 m from an approximate reference in this retrospective case. Geometry is translated and rotated; absolute location and orientation are withheld. This distance is not an accuracy radius. |
| Doppler measured/model comparison | Saved measured harmonic spacing and the frozen bounded-drift model. The recording gap stays visible. Harmonic spacing is not an established engine fundamental. |
| Epilepsy map | R/ggplot2/sf, using U.S. Census 2024 generalized Minnesota county geometry. Seeded illustrative quartiles demonstrate the mapping workflow; they are not actual deprivation estimates or study patient geography. The separate 6,552-patient count comes from the published study. |
| Epilepsy selected forest | R/ggplot2 recreation of the two adjusted estimates available in the abstract: 0.46 (95% CI 0.22–0.96) for Black patients and 2.32 (1.10–4.91) for the highest deprivation quartile. The full covariate table and reference categories are unavailable; this is explicitly a selected-estimate plot. No publisher image was reused. |
| Banking risk–coverage | All displayed curve points recomputed from saved predictions for the 3,080-query test. Frozen semantic threshold 0.66 accepts 2,755 queries, including 96 errors: 89.4% accepted and 3.5% accepted error. Curves explore thresholds; the labeled decision point was chosen separately before test scoring. |
| TrialOps workflow | Two faithful crops of one verified hosted capture from November 15, 2026. A synthetic development question, cached Gemini response, protocol quote and required human review are visible. Callouts annotate original pixels; UI text was not generated or redrawn. This is not a new live capture or a held-out Gemini result. |
| TrialOps handoffs | Saved local rule baseline: 16 true-positive and 7 missed handoffs, plus 21 unnecessary handoffs and 16 true negatives across 60 synthetic tickets. Recall is 16/23 = 69.6%, rounded to 70%. Gemini held-out performance is pending. |
| Finance waterfall | Synthetic FY2025 ledger: budget $1,690,260.00; revenue −$6,895.00; Industrial materials −$55,176.72; other materials +$662.34; labor −$2,061.36; logistics +$105.35; overhead −$4,726.68; actual $1,622,167.93. The six contributions form a complete, nonoverlapping partition. Plot labels round amounts; the vertical axis starts at $1.60M to show the variance. |
