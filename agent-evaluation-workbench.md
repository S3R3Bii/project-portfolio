# Agent Evaluation Workbench

A local workbench for comparing agent outputs against explicit task evidence and keeping failed checks visible.

## What the work demonstrates

Evaluation design; evidence records; reproducible review workflows.

## Scope and next step

A small live judge test passed four of six checks and produced two false passes. It is an illustration of evaluator limits, not a general model ranking.
